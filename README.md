# Stralci

Archivio personale per utenze, password, PIN e codici. Stralci cifra i dati nel browser e li conserva sul dispositivo. Il sito non invia l'archivio a un server e non sincronizza i profili tra dispositivi.

Versione 1.1.0 - 19 ottobre 2026.

Aprire il sito con HTTPS, poi usare **Installa app** in Edge oppure **Aggiungi alla schermata Home** sui dispositivi mobili. Per portare i dati su un altro dispositivo usare il backup cifrato e conservarne la password principale.

Il repository di pubblicazione contiene soltanto i file statici dell'app. Non caricare file personali, esportazioni in chiaro o backup.
